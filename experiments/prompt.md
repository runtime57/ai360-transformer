# Эксперимент: квадратичная J-lens (J-lens + усреднённый гессиан). Режим минимального времени

## Контекст

Ты работаешь на поде RunPod с одной A100 80GB. Постоянный диск — `/workspace`. Код, кэш Hugging Face (`HF_HOME`), чекпоинты и результаты храни только там. Под может остановиться в любой момент, поэтому каждый долгий шаг должен уметь продолжиться с места остановки.

**Главный приоритет — минимальное общее время.** Цель — получить ответ на гипотезы за ~5–8 часов GPU-времени, а не воспроизвести всё максимально полно. Где ниже указан бюджет времени, соблюдай его.

Исследуем Jacobian lens (J-lens):
- Работа Anthropic «Verbalizable Representations Form a Global Workspace in Language Models» (Gurnee et al., 2026): https://transformer-circuits.pub/2026/workspace/index.html
- Код: https://github.com/anthropics/jacobian-lens
- Математический разбор от Alibaba «Short Horizons and Sparse Concepts» (arXiv 2608.25347): https://arxiv.org/html/2608.25347

Определение J-lens для слоя ℓ:

```
J_ℓ = E_{prompt, t, t'≥t} [ ∂h_final,t' / ∂h_ℓ,t ]
lens(h) = softmax( W_U · norm( J_ℓ h ) )
```

Точный оценщик описан в docstring `jlens/fitting.py`: там сказано, как агрегируются позиции-источники t и позиции-цели t'. Прочитай и воспроизведи 1-в-1, а все новые величины (гессиан, целевой вектор y) считай с той же агрегацией.

## Идея

Добавить к J-lens член второго порядка. Пусть `δ = h − μ_ℓ`, где μ_ℓ — средняя активация слоя на корпусе подгонки:

```
f̂(h)     = J̄_ℓ δ + ½ H̄_ℓ[δ, δ]
H̄_ℓ      = E_{prompt, t} [ ∇² f_ℓ ]
lens2(h) = softmax( W_U · norm( f̂(h) ) )
```

## Гипотезы

- **H1.** Усреднённый гессиан ≈ 0: кривизна разных контекстов взаимно гасится.
- **H2** (только если H1 отвергнута). Квадратичная линза точнее J-lens, особенно на ранних слоях. Отдельно смотрим, что происходит с ICR.

## Модели и данные

- **Модели.** Отладка — только на Qwen3-0.6B. Основная — **Qwen3-4B**. Qwen3-8B не запускай; его можно будет добавить позже как подтверждение, если результат окажется интересным.
- **Готовая линза.** Прежде чем подгонять J-lens, за ~10 минут поищи готовую для Qwen3-4B (Hugging Face, Neuronpedia). Если найдёшь, проверь, на каком корпусе и с какими настройками она обучена, и используй её.
- **Подгонка J-lens.** 100 последовательностей × 128 токенов из WikiText-103 (train). В README репозитория сказано, что ~100 промптов уже дают рабочую линзу.
- **Held-out.** 100 последовательностей из WikiText-103 (validation).
- **Контексты для гессиана.** Отдельная выборка из train, не пересекающаяся с held-out.
- **Оценка ICR.** Шесть наборов lens-eval из `data/evaluations/` репозитория anthropics/jacobian-lens. Сначала прочитай README в этой папке и посмотри формат файлов, схему не угадывай.
- **Первые позиции.** Исключай BOS и первые несколько позиций (attention sink) из μ_ℓ, из выборки позиций для гессиана и из PCA. Действуй так же, как репозиторий.

## Правила экономии времени (обязательные)

1. **Отладка только на 0.6B.** Весь код (линза, гессиан, метрики) должен заработать и пройти проверки на Qwen3-0.6B, прежде чем что-либо запускается на 4B. Никаких экспериментов с отладкой на большой модели.
2. **Не пересчитывай префикс.** При возмущении позиции t позиции раньше t не меняются. Один раз прогони чистый проход до слоя ℓ, сохрани KV-кэш и активации префикса, а через хвост сети с forward-mode AD пропускай только позиции не раньше t.
3. **Батчи по максимуму.** Направления δ (или пары направлений) батчуй по одному контексту, подбери максимальный батч под 80 ГБ.
4. **Точность.** TF32 для гессиана (`torch.backends.cuda.matmul.allow_tf32 = True`), bf16 для обычных проходов и подгонки J. fp64 — только для проверки на 0.6B.
5. **Сначала замер, потом запуск.** Перед каждой тяжёлой фазой прогони замер пропускной способности (~5 минут) и экстраполируй.
   - Если прогноз укладывается в бюджет фазы — запускай, не спрашивая меня.
   - Если не укладывается — сначала сам урежь параметры в разрешённых пределах (указаны в каждой фазе). Спрашивай меня, только если и минимальные параметры не укладываются.
6. **Ранняя остановка.** Где описан адаптивный критерий, останавливайся, как только вердикт стабилен.

## Фаза 0. Окружение, пилот, базовая линия (бюджет: ~2 ч, из них GPU ≤1 ч)

1. Установи репозиторий (`pip install -e .`), зафиксируй версии пакетов. Загружай модели с `attn_implementation="eager"` и `use_cache=False` для forward-mode AD; для префикса KV-кэш нужен, сделай это отдельным путём.
2. На 0.6B:
   - подгони линзу;
   - реализуй вычисление `H_c[u, v]` вложенным `torch.func.jvp`. Если forward-mode AD не работает, используй центральную разность JVP первого порядка в fp32;
   - проверь в fp64 против конечных разностей: относительная ошибка должна быть < 1e-3;
   - отдельно убедись, что вариант с повторным использованием префикса даёт тот же результат, что полный пересчёт;
   - реализуй все метрики.
3. На 4B: подгони J-lens (или загрузи готовую) и посчитай базовые метрики. Ориентир от Alibaba для Qwen3-8B: SHL ≈ 0.94, ICR ≈ 18.7. У нас другая модель, поэтому совпадения не ждём, но порядок величин должен быть похожим.

## Фаза 1. Проверка H1 (бюджет: ≤1.5 ч GPU)

- **Слои:** {15, 40, 65, 90}% глубины.
- **Направления:** на каждом слое 100 векторов `δ = h − μ` из held-out (случайные позиции, не первые).
- **Позиции на контекст:** S = 2.
- **Число контекстов N** наращивай блоками 16 → 32 → 64. Это максимум; минимум, до которого можно урезать, — N = 32 и 2 слоя (15% и 65%).

`H_c[δ, δ]` считай вложенным forward-mode AD по хвосту от слоя ℓ. Возмущается только позиция t, выход агрегируется по t' ≥ t как в оценщике J.

**Метрики на каждом слое:**
- **Кривая сходимости:** `‖H̄_N[δ,δ]‖` от N, с нулевой моделью (случайная смена знаков слагаемых, sign-flip). Если среднее ≈ 0, норма падает как 1/√N; если выходит на плато, среднее ненулевое.
- **Относительный размер:** `‖½ H̄[δ,δ]‖ / ‖J̄ δ‖`.
- **Функциональный эффект:** пересечение top-10 считывания с квадратичным членом и без него.

**Ранняя остановка по слою.** После каждого блока сравни `‖H̄_N‖` с `‖H̄_{N/2}‖`.
- Если отношение ≈ 1 и норма как минимум в 3 раза выше нулевой модели, среднее ненулевое. Слой закрыт.
- Если отношение ≈ 1/√2 и норма на уровне нулевой модели, продолжай до N = 64 для подтверждения.

**Вердикт.** H1 подтверждена, если на всех слоях одновременно:
- сходимость неотличима от нулевой модели;
- относительный размер < 5%;
- пересечение top-10 > 0.95.

**Дальше:**
- Напиши `results/phase1/REPORT.md` с числами и графиками.
- Если H1 подтверждена — остановись и отчитайся.
- Если H1 отвергнута — **сразу переходи к Фазе 2, не дожидаясь меня**.

## Фаза 2. Точность и ICR (бюджет: ≤2.5 ч GPU)

### Оценка H̄ в подпространстве

```
z = Uᵀ δ
H̄[δ, δ] ≈ Σ_{i,j} z_i z_j H̄[u_i, u_j]      # храни только i ≤ j
```

- **Подпространство U_J:** top-k PCA J-space-компонент активаций. Каждую активацию разложи по её top-25 J-lens векторам: разреженное неотрицательное разложение, если оно есть в репозитории, иначе проекция на top-25 по скалярному произведению. U_J выбрано потому, что J-space несёт ≤10% дисперсии и обычный PCA может его не захватить.
- **Размер:** k = 16, то есть 136 пар направлений. Контекстов N = 64 при S = 2.
- **Расширение:** только если после этого эффект V2 против V1 заметен и бюджет остаётся — k = 32 или дополнительное подпространство U_pca. Минимум при урезании: k = 8, N = 32.
- **Слои:** 15% + {40, 50, 60, 70, 80, 90}% + последние 3 слоя (они нужны для SHL; хвост там короткий, это дёшево).
- Отчитайся, какую долю ‖δ‖² захватывает подпространство.

### Варианты линз

Все варианты считаются на одном и том же наборе слоёв.

| Вариант | Формула | Зачем |
|---|---|---|
| V0 | `W_U·norm(J̄ h)` | J-lens как у Anthropic |
| V1 | `W_U·norm(J̄ δ)` | Обязательный контроль: отделяет эффект центрирования от эффекта гессиана |
| V2 | `W_U·norm(J̄ δ + ½ H̄_k[δ,δ])` | Квадратичная линза |
| C1 | V1 + случайный вектор той же нормы, что `½ H̄[δ,δ]` | Проверка, что эффект не от любого возмущения |
| C2 | V1 + `½ H̄` с другого слоя | Проверка специфичности по слою; повторно использует уже посчитанное |

### Метрики

**Точность** (held-out, по слоям):
- `‖f̂ − y‖ / ‖y‖` и `cos(f̂, y)`, где y — та же агрегация будущих финальных состояний, что в определении J;
- KL между распределением модели и распределением линзы;
- совпадение top-1 линзы с top-1 модели;
- SHL с последним слоем и без него.

**ICR** (по каждому из шести наборов lens-eval и в среднем):
- **сырой, как у Alibaba:** число ячеек (слой, позиция), где в top-10 линзы есть токен промежуточного концепта;
- **нормированный:** доля промптов, где концепт попал в top-10 хотя бы в одной ячейке на слоях 40–90%;
- **многотокенные концепты:** проверяй первый токен и отдельно укажи их долю.

Все сравнения парные по промптам, с 95% bootstrap-CI (1000 ресэмплов).

**Что явно проверить:**
1. Больше ли выигрыш в точности на ранних слоях.
2. Как изменение ICR связано с изменением SHL. Квадратичный член может «подтягивать» линзу к ближайшему следующему токену в ущерб промежуточным концептам.
