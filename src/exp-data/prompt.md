Задача: реализовать и прогнать один эксперимент. Проверяем, работает ли подмена (swap) невысказанного промежуточного концепта в маленькой GPT, обученной на TinyStories. Сравниваем два словаря для k=16 подпространства: J-lens (Jacobian lens, Gurnee et al. 2026, «Verbalizable Representations Form a Global Workspace in Language Models», https://transformer-circuits.pub/2026/workspace/) и logit lens.

Работай поэтапно и останавливайся в контрольных точках (помечены STOP).



## Определения

**Словари векторов токенов на слое ℓ** (residual stream после блока ℓ):

- logit lens: `v_tok = g ⊙ W_U[tok]`, где g — weight финального `ln_f`;
- J-lens: `v_tok = J_ℓᵀ (g ⊙ W_U[tok])`, где `J_ℓ = E_{prompt, t, t'≥t}[∂h_final,t' / ∂h_ℓ,t]` и h_final — residual после последнего блока, до `ln_f`. Подгонка на 1000 текстах из TinyStories validation, обрезанных до 128 токенов.

Перед любым разложением нормируй вектора в единичную длину. Readout линзы: `softmax(W_U · ln_f(J_ℓ h_ℓ))`; для logit lens J = I.

**Проба концепта X на слое ℓ:** `p_X = mean(h_ℓ на последнем токене промптов из probe-набора для X) − mean по всем животным`.

**k=16 компонента:** неотрицательная k-sparse аппроксимация `p_X` атомами словаря (nonnegative OMP или gradient pursuit, k=16). `c_X` — аппроксимация, остаток `r_X = p_X − c_X`. Считается отдельно для каждого словаря и слоя. Сохрани список 16 токенов и их коэффициенты, а также долю дисперсии пробы, объяснённую `c_X`.

**Подмена s→t по паре направлений (a_s, a_t):** нормируй их в единичные `u_s, u_t`, `V = [u_s u_t]`, `c = pinv(V) h`, `h' = h + α · V (swap(c) − c)`. Применяется на всех позициях промпта и на каждом слое выбранной полосы, то есть «зажато»: правка делается хуком на каждом слое полосы. Компонента h, ортогональная span(u_s, u_t), не меняется.

## Задача и данные

Промежуточный концепт — животное, которое описано, но не названо. Ответ — его звук.

```
Once upon a time, there was a little animal with soft fur and a long tail. It liked to drink milk and chase mice. Every morning it said, "
```

Ожидается `Meow`, промежуточный концепт `cat`.

**Кандидаты животное/звук:** cat/meow, dog/woof, cow/moo, duck/quack, sheep/baa, pig/oink, frog/ribbit, lion/roar, owl/hoot, bee/buzz, horse/neigh, snake/hiss.

### Этап 1. Способности модели

Для каждого животного 5 «названных» шаблонов вроде `Once upon a time, there was a {animal}. Every morning the {animal} said, "`. Посчитай log-prob каждого кандидатного ответа целиком (многотокенные — teacher forcing), во всех вариантах написания: с заглавной и строчной буквы, с ведущим пробелом и без. Для каждого животного определи «золотой» ответ и его токенизацию.

Оставь животных, у которых золотой ответ выигрывает хотя бы в 4 из 5 шаблонов, и золотые ответы попарно различны. Нужно минимум 6 животных.

Проверь, что слово-животное (` cat`, ` dog`…) — один токен; если нет, животное исключи.

### Этап 2. Данные

Для каждого оставшегося животного напиши вручную, в стиле TinyStories:

- **20 описаний**, где нет самого слова и родственных слов (kitten, puppy, calf, duckling…). Используй признаки: внешность, еда, где живёт, что делает. Описания должны быть разными по формулировкам.
- **probe-набор:** 10 описаний с концовками про еду или дом (`It liked to eat`, `It lived in a`).
- **test-набор:** другие 10 описаний с концовкой про звук (`Every morning it said, "`).

Описания в двух наборах не пересекаются и не перефразируют друг друга. Автоматически проверь отсутствие запрещённых слов.

Тестовые промпты, на которых чистая модель **не** выбирает золотой ответ (argmax среди кандидатов категории), отбрасываются. По линзам **не** фильтруй.

### Этап 3. Подгонка J-lens

Подгони J-lens для всех слоёв. Проверь сходимость: сравни J при n=200 и n=1000 (косинус по слоям после flatten).

Sanity-проверки:
- на последнем слое J ≈ I;
- readout logit lens на последнем слое совпадает с выходом модели.

### Этап 4. Чтение

Для каждого test-промпта, для обеих линз и каждого слоя: ранг токена животного на последней позиции. Нужны:

- минимальный ранг по слоям;
- pass@{1, 5, 10, 16};
- графики медианного ранга по слоям для обеих линз;
- для контроля частотного перекоса — тот же ранг в readout от среднего residual по корпусу.

Метрики §4.1 по слоям для обеих линз (графики): excess kurtosis readout, совпадение top-10 линзы с top-1 модели, автокорреляция top-1 по позициям против перемешанного нуля.

### Этап 5. Пробы и разложения

Для каждого животного и слоя: `p_X`, а для каждого словаря (J и logit) — `c_X` (k=16) и `r_X`. Сохрани топ-16 токенов с коэффициентами и долю объяснённой дисперсии.

### Этап 6. Условия подмены

Для каждой линзы L ∈ {J, logit}, пара `s≠t`:

- **C1 raw-token:** `a = v_s, v_t`, словарные вектора токенов животных.
- **C2 k16-компонента:** `a = c_s, c_t`.
- **C3 остаток:** `a = r_s, r_t`. Масштаб подбери так, чтобы средняя ‖Δh‖ совпадала с C2.
- **C4 проба целиком:** `a = p_s, p_t`. Не зависит от L, считаем один раз.
- **C5 случайный контроль:** Δh — случайный вектор с нормой, равной ‖Δh‖ условия C2 на том же испытании.
- **C6 answer swap:** `a = v_{ans_s}, v_{ans_t}`, вектора первых токенов ответов.

### Этап 7. Подбор на dev

Перебери полосы слоёв: каждый одиночный слой и все непрерывные окна длины 2–4. Для каждой полосы перебери α ∈ {0.5, 1, 2, 4}.

Для каждой пары (условие, линза) отдельно выбери лучшую (полосу, α) по success@cat на dev. Сохрани всю сетку: она нужна для графиков успеха по слоям и для H4.

### Этап 8. Тест (без подбора)

Все пары `s≠t` × все test-промпты источника s, с выбранными на dev настройками. Метрики на испытание:

- **success@cat:** ответ t — argmax по полному log-prob среди кандидатов категории;
- **success@top1:** первый токен ответа t — top-1;

Отдельно проверь H4: на dev-сетке одиночных слоёв сравни слой с максимальным эффектом у C1/C2 и у C6.

### Гипотезы (проверять как заданы, не менять после результатов)

- **H1:** success@cat(J, C2) > success@cat(logit, C2).
- **H2:** для каждой линзы C2 > C3.
- **H3:** C2 > C5, C5 ≈ 0.
- **H4:** у подмены промежуточного концепта максимум эффекта на более раннем слое, чем у answer swap.
